# 1. Readiness Vocabulary

- `READY-DESIGN` — required story/claim/visual/spatial contract exists.
- `READY-PREPROD` — execution route, storyboard state, source/reference strategy and fallback are defined.
- `PENDING-ASSET-FREEZE` — exact external file/revision/credit has not been selected.
- `PENDING-AUDITION` — real tool/provider/voice/music behavior must be measured later.
- `OPTIONAL-NONBLOCKING` — omission does not break episode thesis/mechanism.
- `BLOCKED-BY-CODE-LOCK` — implementation/runtime execution is prohibited despite design readiness.
- `BLOCKED-BY-MEDIA-AUTH` — asset download/generation/assembly has not been authorized.
- `NOT-VERIFIED` — cannot be called PASS without real evidence.
