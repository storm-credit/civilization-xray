# 1. Global Storyboard Laws

## G1 — Same hidden world
SH02–SH08 and SH13 must read as the **same representative module**, not similar-looking replacements.

Preserve:
- waterline;
- wall axis;
- canonical X/Z section orientation;
- component identity/order CMP-02→CMP-06;
- same pile-field relationship;
- same load-tracer semantic identity.

## G2 — Reveal escalation
Do not reveal everything at once.

Sequence:
`surface → weak ground → wrong intuition → first pile reveal → isolated module → load path → ground concept → exploded relationship`

Each step should answer one question and open the next.

## G3 — Motion follows information density
- high novelty / low explanation: camera may move more;
- dense mechanism explanation: camera movement reduces;
- proof/counterfactual: near lockoff;
- payoff/reassembly: movement returns.

## G4 — Labels carry qualifiers visually
Repeated narration qualifiers should not all be spoken again if the visual can carry them.

Persistent/recurring labels where relevant:
- `대표 단면`;
- `건물·시기별 차이 있음`;
- `개념도 / 실제 침하량 아님`.

## G5 — History is context, not authority
SH09 may add human presence and temporal texture, but it must not change the mechanism chain or imply an exact documented construction choreography.

## G6 — Bookend payoff
SH01 and SH15 should preferably use the same real Venice source/angle family. The image is similar; the viewer’s mental model is different.

# 2. Storyboard Beat Definitions

## SH01 — Venice Recognition
Story job: B0 orientation.

**First frame**
- recognizable modern canal/building composition;
- clean waterline;
- no technical labels yet.

**Primary visual action**
- subtle 2.5D push/parallax or restrained real-footage movement;
- hold long enough for the viewer to register “Venice,” not “AI city.”

**Narrative handoff**
N001 finishes while the viewer still sees the ordinary surface city.

**Last frame**
- select one stable building edge/wall zone near the waterline;
- composition anticipates SH02’s section axis.

**Transition**
`SCALE_MATCH / registered semantic match` into SH02.

**Source binding**
- preferred VR-06;
- VR-07 fallback.

**Must not**
- no dramatic drone-style spectacle that delays the question;
- no named-building identity unless source-bound;
- no fake underwater reveal yet.

Storyboard verdict: **LOCK**.

# 3. Sequence-Level Timing / Density Guardrails

- SH01–SH04: visual transformation must happen early; do not spend >30s before the viewer reaches the hidden-section question.
- SH04–SH08: longest continuous explanatory run; visual language becomes progressively calmer as information density rises.
- SH09: optional 6–8s bridge, not a new sequence.
- SH10–SH11: evidence-reading section; reduce music/camera density.
- SH12: short causal recap unless rough cut demonstrates a comprehension gap.
- SH13–SH15: payoff accelerates spatial scale outward but reduces factual novelty.

Target effect:
`curiosity → reveal → mechanism comprehension → evidence discipline → proof → reassembly → residual wonder`.
