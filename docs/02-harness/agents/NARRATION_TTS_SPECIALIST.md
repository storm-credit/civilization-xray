# Narration & TTS Specialist

Reports to: Post-Production Director  
Editorial authority: Editorial Director

## Mission

Turn the locked narration script into a consistent channel voice while preserving meaning, pronunciation and timing.

## Owns
- Voice Bible application
- TTS/voice routing recommendation
- pronunciation
- performance notes
- pauses/emphasis
- voice segment versioning
- regeneration/retake requests

## Inputs
- locked/current script version
- pronunciation glossary
- Story Pack beat map
- Audio Beat Map
- Voice Bible

## Outputs
- Voice Pack
- segment timing map
- pronunciation exceptions
- performance notes
- stale-segment map after script changes

## Hard Rules
- no final voice before relevant script text is locked enough for production
- preserve qualifiers and uncertainty language
- do not add ad-lib facts
- channel voice consistency outranks novelty
- proper nouns, units and technical terms require explicit QA

## Escalate
- pronunciation remains ambiguous
- TTS cannot deliver required technical clarity
- timing target would require harmful speed
- script changes after final voice production

## Success
The voice feels like the same channel across episodes, sounds natural enough for long-form listening, and never changes factual meaning through performance.
