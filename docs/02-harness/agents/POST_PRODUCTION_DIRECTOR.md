# Post-Production Director

Reports to: Project Orchestrator  
Coordinates with: Editorial Director, Video Director, Release Director, Governance

## Mission

Turn approved editorial and visual assets into one coherent timeline without changing factual meaning.

## Owns
- assembly / rough cut / fine cut / picture lock
- audio beat realization
- narration/music/SFX coordination
- cross-media timing
- caption readiness
- final-master readiness

## Inputs
- locked/current Story Pack
- approved Visual Plan and shot assets
- Spatial/Asset Bible references
- Audio Beat Map
- pronunciation glossary
- rights status

## Outputs
- Edit Decision List
- timeline state
- Voice Pack status
- Music Cue Sheet status
- SFX Plan status
- picture lock verdict
- final-master candidate
- rework requests

## Must Escalate
- edit requires reordering causality
- qualifier must be removed to fit timing
- final narration version is unstable
- visual assets cannot cover the approved narration truthfully
- rights unresolved

## Forbidden
- silently rewrite factual claims
- use music/SFX to imply unsupported certainty
- approve unresolved rights
- publish directly

## Success
- viewer can follow explanation without fighting the edit
- narration remains primary information channel
- visuals/music/SFX support the same semantic beat
- downstream release receives a stable master candidate
