# Release & Learning Orchestra

Status: **Role architecture — no implementation code**

## Mission

> 완성된 영상의 약속을 정확하게 패키징하고, 공개 후 데이터를 다음 제작의 증거로 되돌린다.

Director: **Release Director**

---

# 1. Hierarchy

```text
Release Director
│
├─ Packaging Strategist
├─ Title / Thumbnail Specialist
├─ Publish Metadata Specialist
└─ Analytics & Learning Specialist
```

---

# 2. Packaging Strategist

Input:
- Episode Brief
- central question
- final master summary
- factual/reconstruction locks

Output:
- packaging angle candidates
- promise statement
- curiosity gap
- forbidden/overclaim list

Rule:
The package may simplify framing but cannot invent a stronger factual claim than the episode supports.

---

# 3. Title / Thumbnail Specialist

Title goals:
- recognizable subject
- one strong unresolved mechanism/question
- avoid redundant thumbnail copy
- preserve truth/qualifier requirements when material

Thumbnail goals:
- one visual idea
- visible mechanism or contradiction
- clear scale/readability
- no fake internal structure presented as documented truth

Thumbnail can reuse approved Spatial/Asset Bible assets but must track version/provenance.

---

# 4. Publish Metadata Specialist

Owns:
- description
- chapters
- source notes
- credits/attribution
- captions upload state
- language/package metadata
- derivative clip references

Does not fabricate citations or overwrite rights requirements.

---

# 5. Analytics & Learning Specialist

Collects/interprets:
- impressions/click behavior where available
- opening retention
- major drop/replay points
- average viewing behavior
- comments signaling confusion/trust
- episode production cost/rework
- thumbnail/title package changes

Distinguishes:
- single-episode anomaly
- topic effect
- packaging effect
- editorial structure effect
- visual explanation effect
- audio/post effect
- repeatable channel-level pattern

---

# 6. Learning Update Protocol

No metric writes directly into Channel DNA.

Flow:

```text
Raw metrics / comments
       ↓
Learning finding
       ↓
Evidence strength
       ↓
Proposed rule/change
       ↓
Project Orchestrator review
       ↓
Channel DNA update or reject
```

A structural rule should usually require repeated evidence across episodes, not one viral/failed case.

---

# 7. Anti-Optimization Guardrails

Do not optimize for CTR/retention by:
- escalating unsupported claims
- misrepresenting historical reconstruction
- cutting necessary qualifiers
- increasing cut speed until comprehension falls
- adding constant music/effects solely to prevent silence
- abandoning the X-Ray explanatory identity for generic spectacle

Trust/clarity gates outrank short-term engagement metrics.

---

# 8. Release Gate

PASS requires:
- final master approved
- captions approved
- rights/provenance complete
- packaging claim passes Fact Governance
- source/credit requirements satisfied
- title/thumbnail have clear central promise
- publish metadata complete
- post-publish learning slot created

Any unresolved rights or critical factual packaging issue blocks release.

---

# 9. Derivative Shorts Boundary

Short clips may be derived from long-form, but they are not allowed to remove context that changes factual meaning.

Each derivative should link to:
- source episode
- source time range
- claim IDs
- visual asset versions
- adapted title/caption

Short-form optimization cannot modify the long-form canonical evidence state.

---

# 10. Physical-Agent Simplification

Phase 1 can combine:
- Release Director + Packaging + Metadata
- Analytics & Learning as a separate review pass

Title/thumbnail visual generation can use existing visual production capabilities, but packaging intent remains Release-owned.
