# Content System

## Channel Promise

> **익숙한 문명 구조를 X-Ray처럼 해부해, 보이지 않는 원리가 어떻게 세상을 움직이는지 보여준다.**

이 채널은 “세계 건축물 소개”가 아니다.

모든 에피소드는 최소 하나의 질문을 만족해야 한다.
- 왜 무너지지 않는가?
- 왜 가라앉지 않는가?
- 어떻게 물/사람/힘/열/신호가 이동하는가?
- 사람들은 당시 기술로 어떻게 만들었는가?
- 어디가 가장 먼저 실패하는가?
- 겉에서 보이지 않는 핵심 구조는 무엇인가?

## Four Positioning Alternatives

### A. World Architecture Explained
유명 건축물을 중심으로 구조 원리를 설명.

장점:
- 썸네일 인지도가 높다.
- 검색 수요를 활용하기 쉽다.

단점:
- 건축 관광/상식과 차별화가 약해질 수 있다.
- 도시·인프라·기계 시스템 확장성이 낮다.

Decision: **Reject as umbrella brand; keep as one content pillar.**

### B. Hidden City Systems
도시 아래/뒤에서 작동하는 인프라 중심.

장점:
- 3D 단면/흐름 시각화에 매우 적합.
- “몰랐던 것”의 놀라움이 크다.

단점:
- 역사·고대 문명 소재가 어색해진다.

Decision: **Keep as strong pillar.**

### C. Historical Engineering
과거 사람들이 기술적 문제를 어떻게 해결했는지 중심.

장점:
- 역사적 갈등과 서사가 강하다.
- 시청자의 “그 시대에 어떻게?” 질문을 만들기 좋다.

단점:
- 자료 불확실성/재구성 리스크가 크다.
- 현대 시스템을 포괄하기 어렵다.

Decision: **Keep as pillar with reconstruction policy.**

### D. Civilization X-Ray — Hidden Mechanisms of Civilization
건축·도시·역사·인프라를 “숨은 작동 원리”로 묶는다.

장점:
- 소재 확장성이 가장 높다.
- 3D 해부 문법이 브랜드 자산이 된다.
- 현대와 고대를 같은 질문 구조로 묶을 수 있다.

단점:
- 주제 선별 규칙이 약하면 잡학 채널이 된다.

Decision: **Selected umbrella positioning.**

# Content Pillars

## P1. Structures
건물, 탑, 경기장, 성벽, 돔, 교량.

질문 예:
- 왜 이 지붕에는 기둥이 없는가?
- 초고층은 바람을 어떻게 흘려보내는가?

## P2. Hidden Cities
지하도시, 배수, 하수, 지하철, 전력, 공동구, 홍수 방어.

질문 예:
- 도시 아래 빗물은 어디로 가는가?
- 바다보다 낮은 도시는 어떻게 살아남는가?

## P3. Historical Engineering
고대/중세/근대의 토목, 공성, 항구, 수도, 성곽, 선박.

질문 예:
- 펌프 없이 산 너머로 물을 어떻게 보냈는가?
- 수천 년 전 거대한 돌을 어떻게 움직였는가?

## P4. Movement Systems
철도, 엘리베이터, 터널, 운하, 공항, 항만.

질문 예:
- 열차는 커브에서 왜 넘어지지 않는가?
- 바다 양쪽에서 판 터널은 어떻게 정확히 만나는가?

## P5. Mega Infrastructure
댐, 방조제, 발전소, 해저시설, 대형 공공 시스템.

질문 예:
- 거대한 댐은 물의 압력을 어디로 보내는가?

## P6. Failure X-Ray
붕괴/침수/화재/과부하를 자극적으로 소비하지 않고 구조 실패 원리로 설명.

질문 예:
- 이 구조에서 한 부품이 사라지면 어디부터 무너지는가?

이 pillar는 사고 영상 재현보다 engineering lesson에 초점을 둔다.

# Topic Scoring Model

후보 주제는 0–5로 평가한다.

1. Familiarity — 사람들이 대상을 아는가?
2. Curiosity Gap — 답을 모르는 질문이 있는가?
3. Hidden Mechanism — 겉에서 안 보이는 원리가 있는가?
4. X-Ray Value — 단면/분해/흐름으로 설명할 가치가 있는가?
5. Visual Continuity Feasibility — 일관된 Hero Object를 만들 수 있는가?
6. Evidence Quality — 신뢰 가능한 자료가 충분한가?
7. Story Tension — 문제→해결 구조가 있는가?
8. Scale/Awe — 규모감/비교가 강한가?
9. Differentiation — 흔한 역사/여행/AI 재현 영상과 다른가?
10. Production Efficiency — 예상 비용 대비 설명 가치가 높은가?

### Hard Reject
- 단면/시각화가 없어도 설명 가치가 거의 동일함
- 핵심 사실을 신뢰할 만한 자료로 확인하기 어려움
- 제목만 자극적이고 실제 mechanism이 약함
- 레퍼런스 채널의 특정 에피소드와 너무 가까운 복제
- AI 재현 장면 자체가 주된 가치이고 숨은 작동 원리/시스템이 없음
- 다른 에피소드의 대본 구조에서 명사만 바꿔도 거의 그대로 작동하는 템플릿형 기획

# Episode Types

하네스 설계를 위해 최소 4개의 대표 episode grammar를 정의한다.

## E1. Mechanism Mystery
“왜 가능한가?”

Flow:
Observed paradox → common assumption → hidden mechanism → layered explanation → payoff

예:
- 베네치아는 왜 가라앉지 않는가?

## E2. Construction Impossible
“당시 기술로 어떻게 만들었는가?”

Flow:
Scale problem → constraints → candidate methods → actual evidence → build sequence → result

예:
- 고대 수도교/피라미드/성곽.

## E3. System Journey
“무언가가 어디서 어디로 어떻게 이동하는가?”

Flow:
Input → route → hidden stages → bottleneck → output → city-scale zoom-out

예:
- 빗물, 상수도, 하수, 전력, 수하물.

## E4. Failure X-Ray
“무엇이 실패하면 전체가 어떻게 무너지는가?”

Flow:
Normal system → load/stress → first failure → propagation → safeguards → lesson

예:
- 댐, 교량, 초고층의 구조적 안전 설명.

### Rule
모든 영상을 하나의 템플릿에 억지로 넣지 않는다. Episode Type이 Script Grammar를 선택한다.

# Initial Season Design

파일럿은 서로 다른 grammar를 시험해야 한다.

추천 4편:
1. Venice foundations — Mechanism Mystery
2. Roman aqueduct — System Journey + Historical Engineering
3. Undersea tunnel alignment — Construction Impossible
4. Supertall wind resistance — Mechanism Mystery / Failure X-Ray

목적:
- 고대/현대
- 건축/도시/인프라
- 물/하중/측량/바람
- 다른 visual grammar

를 모두 테스트해 하네스가 특정 주제에만 최적화되는 것을 막는다.

## Series Rule

초기 20편까지는 pillar별 성과를 관찰한다.
20편 이전에 조회수 한 편만 보고 채널 범위를 급격히 변경하지 않는다.

## Channel Identity Guardrail

주제가 무엇이든 다음 질문에 한 문장으로 답할 수 있어야 한다.

> “이 영상에서 X-Ray로 보여줄, 눈에 보이지 않는 원리는 무엇인가?”

답이 없으면 Civilization X-Ray 소재가 아니다.

# History Adjacency Guardrail — 2026-08-22 Hardening

최근 AI 역사 재현/타임트래블 브이로그/시네마틱 역사 영상이 빠르게 복제되는 시장 상황을 고려해, 역사 콘텐츠의 역할을 명확히 한다.

## Core rule

> **History is a context/pillar. Mechanism is the channel identity.**

Civilization X-Ray는 “AI로 과거를 보여주는 채널”이 아니다.
역사적 시대/사건/사람은 다음을 설명할 때 사용한다.

- 어떤 제약이 설계를 강제했는가
- 어떤 구조/물류/조직 시스템이 작동했는가
- 무엇이 어떻게 이동했는가
- 어떤 선택지가 왜 탈락했는가
- 어디서 실패했고 무엇이 바뀌었는가
- 그 문명이 겉에서 보이지 않는 어떤 시스템에 의존했는가

## Not default Civilization X-Ray formats

다음은 별도 format/brand를 의도적으로 만들지 않는 한 기본적으로 reject한다.

- “고대 로마의 하루” 같은 순수 체험형 AI 역사 브이로그
- 인물 전기 중심 영상인데 숨은 메커니즘이 없는 경우
- 전투 장면의 스펙터클이 핵심인 순수 재현
- 사건을 연대순으로 읽어주는 역사 요약
- 영화 같은 AI B-roll이 narration을 장식할 뿐 설명하지 않는 영상

## Historical episode promotion test

역사 소재는 다음 중 최소 3개를 만족해야 한다.

1. `Hidden Mechanism >= 4`
2. `X-Ray Value >= 4`
3. 하나 이상의 causal chain을 시각적으로 증명할 수 있음
4. 하나 이상의 rejected alternative / constraint / failure logic이 있음
5. 현대 시청자가 표면만 보고는 알기 어려운 시스템이 있음
6. 재구성 장면 없이도 설명 thesis가 성립함

마지막 조건이 중요하다.
AI 재구성 영상이 없어도 thesis가 살아 있어야 한다.

# Anti-Template / Authenticity Guardrail

제작 문법, 카메라 vocabulary, intro/outro, artifact workflow는 반복 가능하다.
하지만 **substance는 episode-specific**이어야 한다.

다음 중 2개 이상이면 `REVISE / REJECT` 후보다.

- 다른 소재명으로 바꿔도 중심 대본이 거의 그대로 작동
- 핵심 explanatory visual의 절반 이상이 다른 에피소드에서 그대로 재사용 가능
- Evidence Pack의 episode-specific primary/technical evidence가 빈약
- Generated cinematic footage가 factual/causal explanation보다 더 많은 비중을 차지
- visual progression이 establishing shot들의 연속이고 reveal/trace/stress/reassembly가 약함
- 고유한 mechanism chain / route / state / tradeoff / failure logic이 없음
- 제목은 역사적 스펙터클을 약속하지만 결말에 고유한 explanatory payoff가 없음

목표는 생산량이 아니라:

> **같은 제작 시스템을 사용하되, 서로 바꿔 끼울 수 없는 에피소드를 만드는 것.**

# Historical Reconstruction Role Classes

역사적 생성 장면은 다음 중 하나로 분류한다.

## HRC-1 CONTEXT
시대·사람·생활·분위기 제공.

## HRC-2 RECONSTRUCTION_SUPPORT
근거가 있는 과정/행동을 이해시키는 보조 재구성. 불확실성/대표성 qualifier 유지.

## HRC-3 EXPLANATORY_PROOF
정확한 순서·공간·상태 자체가 설명 증거인 장면.

HRC-3는 opaque generative video의 기본 역할이 아니다.
대체로 Blender / 2D / real reference / evidence-controlled composite가 우선한다.

AniJam 또는 direct generative video의 historical output은 기본적으로 `HRC-1` 또는 `HRC-2`로 시작한다.
