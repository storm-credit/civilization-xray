# Pattern Validation

## H1. Subject Is Familiar; Mechanism Is the Hook — SUPPORTED

Title pattern is not:
- “후버댐의 역사”
- “네덜란드 건축 소개”

Instead it is closer to:

`familiar subject + surprising constraint/problem + hidden technical solution`

Examples:
- massive concrete → impossible cooling time → engineered cooling intervention
- land below sea level → survival problem → water-control mechanism

### Impact
Our selected umbrella “문명의 숨은 구조” is directionally supported.

---

## H2. Numeric Scale Is Used as Stakes, Not as Trivia — SUPPORTED

Observed title language often uses:
- population/quantity
- years
- counts
- scale

The number creates a physical problem the explanation must solve.

### Civilization X-Ray rule
Use numbers when they change intuition or set constraints.
Do not add numbers merely to make a title look authoritative.

---

## H3. Causal Chain Script Is Likely Central — PARTIALLY SUPPORTED

A publicly reposted excerpt of the Hoover Dam episode describes a chain roughly like:
1. dam geometry/load behavior
2. concrete thermal problem
3. consequence if poured as one mass
4. block construction
5. embedded cooling-pipe solution

This is not a flat list of facts. It is:

`mechanism → new problem → engineered response`

### Impact
Our `Mechanism Chain` beat is reinforced.

---

## H4. Visual Explanation Must Change State — NOT YET EMPIRICALLY VERIFIED HERE

User observation:
- videos appear highly precise and model-like
- structures are visually manipulated/explained rather than only shown

Current environment limitation:
- original frames not fetched reliably

Therefore:
- keep Script ↔ Visual / Spatial continuity design
- do not claim exact camera grammar of the reference channel until frame corpus is available

---

# Format Caveat

One public analytics service currently classifies many recent visible uploads from the reference channel as short-form videos around the 1-minute range.

This does **not** settle the format of the specific user-provided YouTube link and should not override direct observation of that video.

Design implication:
- We are not trying to clone the reference channel’s runtime.
- Civilization X-Ray remains designed as a **long-form adaptation of the explanatory grammar**, with Shorts/short clips considered derivative outputs.

# What We Can Learn Already

## Learn

- familiar subject with unfamiliar mechanism
- engineering problem→solution chain
- scale used to create stakes

- average shot length
